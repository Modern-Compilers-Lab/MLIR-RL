- bug: promotion with `memref.alloc`/`memref.dealloc` fails in `buffer-deallocation-pipeline` ("memory free side-effect on MemRef value not supported") -> fix: use `use_alloca` in `transform.structured.promote` to use stack allocation instead
- bug: `transform.bufferization.one_shot_bufferize` cannot target an intermediate `match ops{["module"]}` result handle -> fix: apply it directly to the consumed `%module` entry-point handle; the op returns a new handle
- bug: `match ops{["func.func"]}` returns multiple handles when `nanoTime` private func exists, causing "requires exactly one target handle" -> fix: match `attributes{tag = ...}` directly in `%module`/`%arg1` instead of through `func.func`
- bug: `transform.loop.unroll` and `transform.loop.peel` invalidate handles to ops nested inside the loop being unrolled/peeled -> fix: annotate the tiled op with its tag BEFORE unrolling/peeling the loop
- bug: `transform.loop.peel` requires `!transform.op<"scf.for">` type, not `!transform.any_op` -> fix: use `!transform.op<"scf.for">` for the loop result type in `tile_using_for` output and peel input
- bug: `transform.loop.peel` fails with "failed to peel the last iteration" when loop bound divides evenly by tile size -> fix: use `fail_if_already_divisible = false` attribute, and choose tile sizes that don't divide the target dimension for meaningful peeling
- bug: conv2d has windowed access patterns (d2+d5, d3+d6 in indexing maps) that prevent direct vectorization ("Attempted to vectorize, but failed") -> fix: convert to img2col first via `transform.structured.convert_conv2d_to_img2col`, then tile and vectorize the resulting 4-dim contraction
- bug: `transform.structured.promote` attributes without braces (e.g. `operands_to_promote = [0, 1, 2] use_alloca`) causes parse error ("expected ':'") -> fix: use attr-dict braces syntax `{operands_to_promote = [0, 1, 2], use_alloca}`
