**Key findings:**
- **Vectorization is TERMINAL**: After vectorization, the linalg op is replaced with vector dialect ops (vector.transfer_read/write, vector.multi_reduction). The tag moves to the wrapping scf.for loop. All subsequent actions pass precondition (they find the tag) but fail postcondition (no structural change applied).
- **Unrolling is TERMINAL**: After unrolling, inner linalg.matmul ops get tag "unrolled_inner" while the outer loop gets tag "operation_0". Subsequent actions find the tag on the scf.for loop but cannot transform it, leaving code unchanged and failing postcondition.
- All other 5 actions (Tiling, LoopInterchange, Promotion, ParTiling, ParDirect) compose freely with all 7 actions.
