### Phase 4 Summary
- **9 parameter variants tested** around the best schedule
- **Optimal configuration**: Para[4,4] + Promo[32,32,32] + Vec[8,8,8]
- Key tuning insights:
  - Thread count: 4x4=16 threads is optimal; 2x2=4 is too few, 8x4=32 slightly oversaturates
  - Promotion tile size: 32 is optimal (8KB/operand fits L1); 64 causes L1 cache thrashing (32KB/operand)
  - Vector size: [8,8,8] is optimal; [4,4,4] underutilizes SIMD, [16,16,4] has suboptimal shape
  - Promotion > Tiling > Unrolling as the middle action (data locality from contiguous buffers wins)
