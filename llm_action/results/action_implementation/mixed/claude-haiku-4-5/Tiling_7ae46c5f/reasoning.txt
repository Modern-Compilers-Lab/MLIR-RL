- **Parameters**: `tile_sizes` (list of positive integers matching the loop structure). Position-based semantics: tile_sizes[0] tiles the outermost loop, tile_sizes[1] the next, etc. A value of 0 means "no tiling for this loop."

- **Preprocessing**: Identity (no canonicalization needed for tiling).
- **Implementation**: Use `transform.structured.tile_using_for` to tile the target operation with the provided tile sizes.
- **Postcondition**: Verify the IR changed (not a no-op) and still contains valid `func.func`.
