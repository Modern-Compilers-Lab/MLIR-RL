### `transform.structured.tile_using_for`
Tiles a linalg op by generating a loop nest with a smaller tiled target operation in its body. Currently limited to LinalgOps.

**Operands:**
- `target`: TransformHandleTypeInterface (the linalg op to tile)
- `dynamic_sizes`: variadic (optional, for dynamically computed tile sizes)

**Results:**
- `tiled_linalg_op`: handle to the tiled operation in the loop nest
- `loops`: variadic handles to the generated `for` loops

**Attributes:**
- `static_sizes`: i64 dense array (tile sizes; `0` means no tiling, `ShapedType::kDynamic` means dynamic)
- `interchange`: i64 dense array (optional; loop interchange order)
- `scalable_sizes`: i1 dense array (optional; for scalable dimensions)

### `transform.structured.tile_using_forall`
Tiles a TilingInterface op to a tiled `scf.forall` (parallel loop).

**Operands:**
- `target`: TransformHandleTypeInterface (the op to tile)
- `num_threads` or `tile_sizes`: variadic (either specify thread count or tile size per dimension)

**Results:**
- `tiled_op`: handle to the tiled operation
- `forall_op`: handle to the generated `scf.forall`

**Attributes:**
- `static_num_threads`: i64 dense array (when using `num_threads`)
- `static_tile_sizes`: i64 dense array (when using `tile_sizes`)
- `mapping`: optional device mapping attribute

## Answer

There are **two main tiling operations** for linalg operations:

1. **`transform.structured.tile_using_for`** — Generates a sequential loop nest (`scf.for` loops) around the tiled operation.
2. **`transform.structured.tile_using_forall`** — Generates a parallel loop (`scf.forall`) suitable for multi-threaded execution.

**Key facts:**
- Both require a `target` handle (the linalg operation to tile).
- Tile sizes are specified via `static_sizes` / `static_tile_sizes` attribute (dense i64 array).
- A static size of `0` means "do not tile this dimension"; dynamic sizes use `ShapedType::kDynamic` placeholder with corresponding operand.
- `tile_using_for` returns `(tiled_linalg_op, loops)`; `tile_using_forall` returns `(tiled_op, forall_op)`.
- The operation validates that `target` contains only Linalg ops; non-Linalg ops cause a silenceable failure.

## Constraints / Preconditions

- **Payload IR must contain Linalg ops** — Non-Linalg operations cause silenceable failure.
- **Tile sizes must match the operation's iteration domain** — One entry per loop dimension in the linalg op.
- **Static size `0` = no tiling for that dimension** — All zeros makes the transform a no-op.
- **Dynamic sizes** — If using `ShapedType::kDynamic` in `static_sizes`, a corresponding handle must be provided in `dynamic_sizes`.
- **Handle type** — `target` must be `!transform.any_op` or other TransformHandleTypeInterface-compatible type.
- **Result unpacking** — Both returns are variadic; use destructuring (e.g., `%tiled, %loops:N = ...`) with correct arity.
