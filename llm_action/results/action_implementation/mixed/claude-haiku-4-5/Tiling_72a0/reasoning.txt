I am tasked with implementing the **Tiling** transformation as a Layer-2 action. The input describes:

- **Intent**: Cache Locality & Memory Efficiency
- **Transformation**: Tiling — partition loop nests into rectangular blocks fitting in L1/L2 cache
- **Action Template**: `Tiling(tile_sizes)` where `tile_sizes` is a list of positive integers or zeros

## Approach

The tiling transformation will:

1. **Parameters**: Accept a list of `tile_sizes` (one per loop in the target operation's loop nest). A size of 0 means no tiling for that loop.

2. **Precondition**: 
   - Verify `tag = "operation_0"` exists in the code
   - Verify `tile_sizes` is a non-empty list of non-negative integers
   - Verify that not all tile sizes are zero (avoid no-op)
   - Verify the target operation is a structured op that can be tiled (linalg.* or lowered to scf/affine)

3. **Preprocess**: Identity (no special preparation needed)

4. **Implement**: 
   - Use MLIR Transform dialect `transform.structured.tile_using_for` to apply tiling
   - Match the operation via `tag = "operation_0"`
   - Apply tile sizes as specified
   - Return the transformed IR

5. **Postcondition**:
   - Verify the IR changed (not a no-op)
   - Verify the IR is still valid (contains `func.func`, parses correctly)
   - Reject if the transform produced identical code
