**Operation:** `transform.structured.tile_using_forall`

Tiles a TilingInterface op (e.g., linalg operations) to a tiled `scf.forall` loop.

**Key points from documentation:**
- Tiling is applied by specifying either `num_threads` or `tile_sizes` (mutually exclusive intent, but syntax allows mixing).
- Static zero tile sizes mean the dimension is not tiled (full data size).
- `num_threads` and `tile_sizes` can be static index attributes or operation handles.
- If `mapping` is non-empty, it is added as an attribute to the resulting `scf.forall`.
- Returns **two handles**: the tiled operation and the new `scf.forall` operation.

---

## Answer

1. **Target operand**: Pass a handle matching the linalg operation(s) to tile. Usually obtained via `transform.structured.match`.

2. **Tiling spec**: Use **either** `num_threads [...]` or `tile_sizes [...]`:
   - `num_threads [N1, N2, ...]`: Tile size per dimension is calculated as `ceilDiv(dimSize[i], num_threads[i])`.
   - `tile_sizes [S1, S2, ...]`: Static or dynamic tile size per dimension. Use `0` to skip tiling a dimension.

3. **Operand types**: Tile sizes/num_threads can be:
   - Static index attributes (integer literals in the syntax).
   - Operation handles (must map to exactly one op with exactly one index-type result).
   - Mixed: e.g., `[0, %handle, 20]`.

4. **Result types**: Returns **two handles**:
   - `tiled_op`: The result of the tiled operation.
   - `forall_op`: The newly created `scf.forall` loop.

5. **Optional mapping**: Use `mapping = [...]` to attach device mapping attributes to the `scf.forall`.

6. **Failure semantics**: Ops that don't implement TilingInterface are dropped. Returns silenceable failure if any op doesn't tile successfully.

## Constraints / Preconditions

- **TilingInterface requirement**: The target operation must implement `TilingInterface` (e.g., linalg ops do).
- **Dimension safety**: It is the user's responsibility to ensure `tile_sizes`/`num_threads` only tiles parallel dimensions. Non-parallelizable dimensions will generate a warning.
- **Handle semantics**: If using operation handles in tile_sizes/num_threads, each handle must map to exactly one op with exactly one index-type result.
- **Zero tile sizes**: Static `0` in tile_sizes means "do not tile this dimension" (use full size).
- **Static attributes**: Use `DenseI64ArrayAttr` for `static_num_threads` and `static_tile_sizes` internally if constructing the op programmatically.
