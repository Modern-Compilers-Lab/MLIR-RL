**`transform.structured.interchange`** (`transform::InterchangeOp`)

The operation interchanges the iterators of operations pointed to by the target handle using the `iterator_interchange` attribute.

**Key Parameters:**
- **`target`**: A TransformHandleTypeInterface instance pointing to operations to interchange
- **`iterator_interchange`**: A `DenseI64ArrayAttr` containing non-negative i64 values representing the permutation

**Return Modes:**
- Ignores non-linalg::Generic ops and drops them.
- Fails if the interchange attribute is invalid.
- Returns a handle pointing to successfully interchanged operations (may be empty).

## Answer

1. **Operation name**: `transform.structured.interchange`
2. **Target**: Must be a handle to a structured operation (e.g., `linalg.generic`, or similar `linalg.*` ops that support iterators)
3. **Permutation**: Specify the loop order via the `iterator_interchange` attribute as a dense i64 array
   - Example: `[1, 0, 2]` means swap first two loops, keep third in place
4. **Return value**: A new handle pointing to the successfully interchanged operations
5. **Failure mode**: Non-linalg::Generic ops are ignored; if interchange fails on any op, the entire transform fails
6. **Precondition**: Target must be a valid structured operation with iterators compatible with the permutation
